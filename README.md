# FitLife Fitness — Al Bustan, Ajman

Website for FitLife Fitness: plain HTML, CSS and JavaScript in `dist/`, with no build step.

## Deploy to Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/beko2499/fitlife-fitness-ajman)

1. Click the button and sign in to Render (signing in with GitHub is quickest).
2. Click **Apply**. Render reads `render.yaml` and publishes `dist/` as a free static site.

Every push to `main` redeploys the site automatically.

## Preview locally

```bash
npm run dev
```

Then open http://127.0.0.1:4173.
